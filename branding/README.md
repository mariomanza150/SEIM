# Institution branding packs

UAdeC is the packaged default. Copy `uadec\` to a new folder (for example `myuni\`), edit `config.json`, put logos in `logos\`, and point SEIM at the pack.

See `documentation\white_labeling.md` for env vars, CSS, and CMS seed notes.

Local overrides (not committed): copy `institution.json.example` to `institution.json`.
