CMS Module (Wagtail)
====================

The ``cms`` app integrates **Wagtail 7** for the public marketing site at ``/`` and
the CMS admin at ``/cms/``.

Overview
--------

* Page types (homepage, blog, program listings, FAQs)
* StreamField blocks and institution branding hooks
* ``manage.py restore_cms`` / export-import commands
