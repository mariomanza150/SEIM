Workflows Module
================

The ``workflows`` app manages configurable application workflow definitions and
state transitions used by the exchange application pipeline.

Overview
--------

* Workflow definitions and steps
* Integration with ``exchange`` application status transitions
* Staff configuration via Vue admin at ``/seim/admin/``
