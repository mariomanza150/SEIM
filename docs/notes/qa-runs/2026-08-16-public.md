### 0.2 Swagger UI (`url-routing`) — **Fail** (High)

- **URL:** `http://localhost:8020/api/docs/`
- **Saw:** `200` HTML, `<title>SEIM API</title>`, Swagger UI bundle, schema URL relative `/api/schema/`. Servers in schema: `/` (same origin), then `:8001` / `:8000` / production. Relative `/` is correct for 8020 (note only).
- **Defect:** Schema tag list includes `programs` and `applications`, but **no matching paths**. **No calendar operations at all.** Live probes:
  - `GET /api/documents/` → `401 application/json` (DRF)
  - `GET /api/notifications/` → `401 application/json`
  - `GET /api/grades/scales/` → `401 application/json`
  - `GET /api/programs/` → `404 text/html` Wagtail “Not Found” (179 bytes)
  - `GET /api/applications/` → same 404 HTML
  - `GET /api/calendar/events/` → same 404 HTML
- **Root cause (this image):** container `/app/exchange/urls.py` is a stub (`urlpatterns = []`, 1 line). Host source has the full SimpleRouter (`programs`, `applications`, `calendar/events`, …). Spectacular therefore omits those groups; Wagtail catch-all serves HTML 404.
- **Repro:**
  1. Open `http://localhost:8020/api/docs/` (or download `/api/schema/`).
  2. Search for `/api/programs/`, `/api/applications/`, `/api/calendar/`.
  3. `curl.exe http://localhost:8020/api/programs/` → HTML 404, not DRF JSON.
  4. `docker compose -p seim-localprod -f docker-compose.local-prod.yml exec web cat /app/exchange/urls.py` → `urlpatterns = []`.
